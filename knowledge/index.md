# 平台资料目录

南大表格（table.nju.edu.cn，SeaTable 6.2）的表格和应用资料。内容主要来自 SeaTable 官方帮助、官方 API 文档和官方前端库，并改写成本插件的工具写法。

| 文件 | 内容 |
|---|---|
| columns.md | 各列类型的 column_data 写法、行里的值、单选、链接、链接公式、按钮、列默认值、修改列类型 |
| formulas.md | 公式写法和全部函数（if、countlinks、rollup、日期函数等） |
| filters.md | 过滤条件结构、各列类型可用的条件、filter_term 写法、"当前用户"条件、哪些地方用过滤 |
| app.md | 应用配置整体结构、页面 id 和导航、页面类型一览、应用级设置、修改流程 |
| form-page.md | 表单页：字段设置、默认值、条件显示、链接字段、备注、提交后跳转、防重复 |
| table-page.md | 表格页：显示列、只读列、固定过滤、排序、链接列设置、按钮、权限 |
| other-pages.md | 画廊、看板、日历、时间线、查询、单条记录、自定义页 |
| permissions.md | 页面权限项、角色、用户、邀请链接、自助加入 |
| patterns.md | 常见做法：只看自己的记录、自动记录提交人、状态按钮、级联选择、名额上限、防重复、提交后跳转 |

用 docs 工具：
- `search` 按关键词查，例如 "按钮 modify_row"、"include_me"、"条件显示"、"名额"；
- `read` 读整篇或其中一节。
